# 반복 없는 자동 추억영상

`MemoryVideoRequest`와 `memory` CLI의 기본 백엔드는 `ltx23_film`이다. 사진 번호나 편집 구간을 작업자가 지정하지 않는다. 이전 단일 생성은 `backend=ltx23`로 명시한다.

1. 원본 디코딩·방향 보정·OpenCV 초점/노출 검사. 지원하지 않는 파일은 이유를 기록한다.
2. 최대128개 후보를 여행 전체에서 검토하고, 이미지 모델이 주요 피사체의 초점과 움직임 가능성을 분석한다. 배경만 선명한 사진은 피사체 검사에서 제외할 수 있다.
3. 서로 다른 기억 단위로 묶고 장면과 원본을 재사용하지 않는다. 30초는 움직임과 가용 장면 수에 따라 보통10–15개다. 10개·5개의 서로 다른 기억이면 그 수에 맞춘다. 소수 후보에서는 예비 장면을 남긴다.
4. 장면별 FLF 후보를 생성한다. 현재 설정은 실제1024×576·24fps, 최소12초 소스다. 한 장뿐인 장면은 동일 사진을 양 끝 가이드로 사용하되 끝 가이드를 약하게 적용해 고정을 줄인다. 서로 무관한 사진을 억지로 연결하지 않는다.
5. OpenCV 영상 지표와 참조 사진 기반 모델 검수를 모두 통과한 연속 구간 하나만 사용한다. 정지·형태 변형·장소 혼합·새 동행인 등의 실패를 검사한다. 검사 모델 장애는 통과로 처리하지 않는다.
6. 제한된 재생성·예비 장면 교체 후에도 실패하면 실패를 반환한다. 같은 영상 반복·정지 사진 삽입으로 길이를 채우지 않는다.
7. 정확한 프레임 수로 편집하고 제목·선택 음악·음량 처리를 적용한다. 1080p 출력은 확대 출력이며 원본 확산 해상도와 구분한다.

```bash
python -m scripts.video.run memory --input-dir /photos \
  --workspace /persistent/video-jobs --music-file /music/selected.wav
```

`AUTO` 작곡은 별도 음질 검사를 적용하며 실패할 수 있다. 검증된 음원을 파일로 지정할 수 있다. 이 실행에서는 기존 검증 음원을 사용했다. 음악 선택 UI와 HTTP 영상 접수 계약은 별도 백엔드 연동 대상이다.

ComfyUI 모델·GPU는 미리 준비된 작업 서버에서 제공한다. FFmpeg·한글 폰트·OpenAI 키·영구 작업 저장소가 필요하다. 개발 검증용 RunPod 생성/중지는 서비스 실행기의 기능과 분리한다.

실패 작업은 내부 Python `generate_diverse_film(..., same_folder, resume=True)`로 이어서 처리한다. 요청 지문이 다르거나 제공자 제출 상태가 불명확하면 재개를 거부한다. 완료된 장면을 보존하며 다운로드는 동일 자산에 한해 제한적으로 다시 요청한다. 백엔드는 작업 저장소를 사용자별로 보호해야 한다.

이 검사는 일정한 검수 절차를 적용하는 장치이며 모든 입력에 대한 상업적 품질 보증이 아니다. 초점·움직임 임계값과 모델 판정은 휴리스틱이다. 5/10/100개 합성 목록 테스트는 반복·길이·선택 규칙 검증이며 실제 여행사진의 품질 일반화 실험을 대신하지 않는다. 서로 다른 실제 사진 묶음과 사람의 평가를 계속 축적해야 한다.

## 소수 사진 앨범의 실패 복구

사진 쌍의 생성이 반복 실패하고 예비 장면이 없으면 첫 참조 사진을 양 끝 가이드로 쓰고 카메라를
고정해 복구를 시도한다. 계속 실패한 장면은 건너뛰고 다른 장면의 생성을 계속한다. 재개 시에는
accepted 목록의 순서가 아닌 원래 slot을 이용해 실제 영상 파일을 찾는다.

10장 이하·계획 장면 6개 이하의 앨범에서 통과 장면이 부족하면, 단독 생성에 아직 사용하지 않은
사용 가능한 사진을 최대 2장까지 추가 후보로 검증하는 복구 패스를 한 번만 수행한다.
낮은 움직임 가능성 때문에 초기 구성에서 빠진 사진도 추가 후보가 될 수 있지만, 실제 영상의
움직임·형태·인물 검수를 면제하지 않는다. 30초 소수 앨범의 재배분에는 최소 5개 통과 장면이
필요하며 각 구간을 최대 6초로 제한한다. 더 많은 계획 장면이 있는 앨범의 기존 기준은 유지한다.

독립 인물 검수에서는 원본과 생성본에 동일하게 남은 불분명한 형상 자체를 새 전경 인물로 보지
않도록 명시한다. 새로 나타나거나 얼굴·신체가 구체화된 인물은 계속 거부한다. 실제 실패 사례와
함께 비교 검수해야 하며 이 보완이 검수기의 정확도 향상을 통계적으로 증명한 것은 아니다.

2026-11-03 강릉 사진 8장 검증에서는 고정 길이 30초 자동 완성에 실패했다. 더 긴 구간을
사용한 24초 검수도 통과하지 못했다. 통과했던 원래 구간을 그대로 보존해 기존 렌더러로
473프레임(약 19.7초), 4개 장면을 편집해 보관했다. 이는 고정 30초 생성 성공 사례가 아니며,
실패 작업에서 자동으로 짧은 길이를 결정·제공하는 제품 정책과 백엔드 계약은 아직 별도다.
