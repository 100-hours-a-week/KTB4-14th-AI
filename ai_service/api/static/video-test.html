영상 서비스 테스트

사진 여러 장을 올리고 영상을 요청한 뒤, 진행 상황과 완성 영상을 확인합니다.

1. 로그인 정보

토큰은 이 탭에만 기억해서 새로고침해도 유지되고, 탭을 닫으면 지워집니다.

2. 사진 올리기

파일 선택 창에서 Shift 또는 Cmd(Ctrl)를 누른 채 여러 장을 고를 수 있습니다. 최대 120장. 올리기 전에 긴 변 2560px로 줄여서 4개씩 동시에 보냅니다.

    3. 영상 만들기

    서비스 토큰을 입력하면 선택할 수 있는 GPU가 표시됩니다.

    GPU가 꺼져 있으면 요청이 들어올 때 켜지고, 켜지는 동안은 "GPU를 켜는 중"으로 표시됩니다. GPU가 일한 시간만큼만 요금이 나갑니다.

    4. 진행 상황

    내 영상 작업 · 새로고침해도 여기서 다시 고를 수 있습니다
    • 토큰을 넣으면 내 작업 목록이 나타납니다.
